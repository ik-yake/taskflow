## Descripción

TaskFlow optimiza el flujo de trabajo en equipo facilitando la creación, asignación y seguimiento en tiempo real de las actividades dentro de un proyecto.

---

## Funcionalidades

- [x] Registrar nuevas tareas
- [x] Editar tareas existentes
- [ ] Eliminar tareas desactualizadas
- [ ] Asignar tareas a usuarios específicos
- [ ] Notificaciones de vencimiento

## Requisitos

Antes de iniciar el proyecto, asegúrate de contar con las siguientes herramientas instaladas:

- **Node.js** (v16.0 o superior)
- **MySQL Server** (v8.0 o superior)
- Un navegador web moderno (Chrome, Edge, Firefox)
